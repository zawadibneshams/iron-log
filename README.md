# Iron Log

**[Open the app →](https://zawadibneshams.github.io/iron-log/)**

A free, personal home-gym workout tracker. Log routines, sets, and reps for a 7-day split, track PRs, use the built-in rest timer, and follow your body weight and measurements over time — all saved locally in your own browser, no account needed.

## Getting started
Just open the link above. On iPhone, use Safari's "Add to Home Screen" (Share → Add to Home Screen) to install it like an app.
